# ZP Imports

Protótipo da loja e do painel de operação da ZP Imports (pedidos, separação, rotas, entregadores e pagamentos por link).

- `index.html`: o protótipo (funciona sem servidor, os dados ficam no navegador).
- `docs/`: procedimento operacional e plano de implantação com Supabase e Netlify.

Este repositório é privado. Não coloque chaves secretas aqui (apenas a chave pública do Supabase pode ir no código).
